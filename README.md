# AstroDB

TUI for querying, cleaning, and persisting astronomical database records.

Targets Virtual Observatory services (VizieR, SIMBAD, and others) via ADQL over pyVO.

## Install (Homebrew)

```bash
brew tap lldddv2/astrodb
brew install astrodb
```

Then launch:

```bash
astrodb
```

## Install from source (development)

```bash
uv pip install -e .
astrodb
```
